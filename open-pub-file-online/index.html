How to open a .pub file without Publisher

A .pub file is a document made in Microsoft Publisher, a program for flyers, newsletters, brochures and cards. If you do not have Publisher, you can still see what is inside. Here are your options.

Your options

1. Convert it to PDF in your browser (fastest)

The PubToPDF converter turns a .pub file into a PDF that opens anywhere. It runs on your own device, so your file is never uploaded. It is free, needs no account, and works on Chromebook, Mac, Windows and Linux.

2. Use the free LibreOffice program

LibreOffice can open .pub files in its Draw program and export them as PDF. It is a good choice if you want to keep working on the design, but it means downloading and installing a large program, and some layouts will not look identical.

3. Use an online converter that uploads your file

Many websites convert .pub files, but they do it by sending your file to their servers. That may be fine for a party invitation. It is not a good idea for files with private information, student records or business documents.

4. Ask the sender for a PDF

If someone sent you the file, ask them to open it in Publisher and choose File, then Save As, then PDF. That gives the most exact copy.

Frequently asked

Can Word or Google Docs open a .pub file?

No. Neither program understands the Publisher format. Convert the file to PDF first. See how to get a .pub file into Word.

Can I get the text out of a .pub file?

Yes. Convert it to PDF, then copy the text from the PDF. Most PDF viewers let you select and copy text.

Is a .pub file the same as a .pdf?

No. A .pdf is a finished copy for viewing and printing. A .pub is the editable working file for Publisher.
