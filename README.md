# PubToPDF

Free, private converter for Microsoft Publisher (`.pub`) files.

**Use it here: https://landolrian.github.io/pubtopdf/convert/**

- Turns `.pub` files into PDF right in your browser
- Files are never uploaded; conversion runs on your own device
- Convert one file or a whole batch and download them as a ZIP
- Works on Chromebook, Mac, Windows and Linux, with nothing to install

Microsoft Publisher is being retired in October 2026. See the guide: https://landolrian.github.io/pubtopdf/publisher-shutting-down/

Conversion is powered by open-source LibreOffice technology (via ZetaOffice). PubToPDF is not affiliated with Microsoft.
